<div align="center">
<h1>SignSniper Client</h1>

用于接收和发送动态二维码的客户端
</div>

## 使用前提
你有一个服务器地址。可通过询问室友，或部署[服务端](https://github.com/ZongziTEK/SignSniper-Server)获得它。

## 发送模式
仅在 Android 端可用。将手机对准动态二维码。软件将持续扫码，当二维码变化时，发送二维码内容至服务端。

## 接收模式
从服务端实时获取当前的动态二维码，并显示。

接收模式设备 ≠ 签到设备。请用另一台设备展示二维码，再用自己的手机扫码。

## 配置
### 服务器地址
填写服务器地址。应与室友的服务器地址一致。
### 频道
若你与室友是第一次使用本软件，则输入一个频道（内容随意），或点按“随机”按钮以获得一个随机频道。将该频道发送给室友。

若你收到他人给你的频道，则将该频道粘贴进文本框。你将在该频道接收或发送二维码。
